How to read the numbers in this document

Every accuracy figure carries the protocol that produced it, because figures from different protocols are not comparable and mixing them is the most common way to state something false about this project. There are four protocols in use and they are defined in Part 9. Where a number has no protocol attached, it is a property of the code or the hardware rather than a measurement of accuracy.
